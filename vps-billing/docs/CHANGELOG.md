# 变更记录

## 本次维护候选：品牌、双语与双币种

基线：338d98b23bf190198a0efa34b7200aabc4ead35c；继续自 dc489395428b664a6664ed4c1a679007b184f7c7。最终提交和构建标签由发布目录 BUILD.json 记录；本文件不冒充正式 tag 或已发布 Release。

### 新增与调整

- 管理员站点设置：公司/站点名、支持邮箱和 HTTPS 链接、展示地址、预设 logo/theme、邮件署名、账单开具抬头/地址与默认语言/币种。设置有权限、CSRF、revision 冲突和事务审计；提供预览与高级选项。
- 简体中文和 English、CNY 和 USD 两个独立选择项；默认中文/CNY。语言不改变币种，输入的运营/产品资料不自动翻译。
- 服务端 plan_prices 独立报价，订单按所选币种取价和检查可售状态；没有汇率或自动换算。币种纳入幂等指纹，金额/统计遵守安全整数范围。
- 订单与账单记录创建时的金额、币种、issuer 快照；旧记录缺少身份时保持缺失。统计按币种，不用最多 1,000 条列表计算财务汇总。
- 迁移 1/2/3 保持原文；新增订单快照/金额精度及二进制币种约束迁移，完整历史 checksum 与已知中断恢复处理。
- Linux amd64 提交快照打包、确定性归档/校验和、工具链与依赖/license 清单；增加原生服务配置与安装、升级、回滚、恢复文档。

### 修复

- 强制 MySQL TLS 时禁止显式允许明文回退。
- 登录限速规范化 IPv6，避免同一地址文本别名分散限速预算。
- JSON 请求验证真实媒体类型，拒绝伪装的 application/json 后缀。
- 管理员账单详情使用专属只读路由；账单弹窗处理旧响应迟到。
- 并发备份使用独占临时文件和随机后缀，校验和可随备份搬到其他目录。
- MySQL 初始化脚本打入镜像并固定执行权限，避免宿主机受限文件模式导致 runtime 账号初始化缺失。
- 更新测试依赖并复核 npm 审计；最终扫描范围/结果见 VALIDATION.md，不把扫描可用性问题写成零漏洞。

### 升级注意

旧二进制可能拒绝新版 schema，没有向下迁移；升级前必须备份和隔离恢复。新 CNY 示例价格不可售，既有 USD 可售状态可被迁移保留，需人工复核产品和价格。套餐价格暂无后台编辑器，见 SITE_SETTINGS.md 的受控 SQL 流程。
