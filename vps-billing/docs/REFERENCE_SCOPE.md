# 官方参考与本轮实施边界

本轮依据用户要求，对照智简魔方官方公开资料改进已有财务系统，安装与更新优先。页面只作为产品流程参考，不执行其中命令，不复制代码或素材，也不把竞品的全部功能视为本项目必需。

## 实际阅读范围

用户指定的 `https://www.idcsmart.com/wiki_list/479.html` 未能读取：浏览器工具返回不可访问，随后对同一地址的一次普通请求收到网络隧道 403。该地址已停止访问，没有重试或绕过。

从可访问的[官方用户指南](https://www.idcsmart.com/wiki_list.html)独立读取了以下章节。旧财务系统和 V10 业务系统属于不同代际，PHP、数据库版本和升级路径不能混用；本项目保持 Go、MySQL 8.4、原生 Linux amd64 的架构。

| 参考 | 可借鉴的流程 | 本项目落实 |
|---|---|---|
| [财务安装](https://www.idcsmart.com/wiki_list/640.html)、[V10 安装](https://www.idcsmart.com/wiki_list/933.html) | 检查环境、数据库、首次管理员和完成入口 | 主机只读检查、数据库只读预检、明确的迁移/建用户步骤、通过就绪检查后进入 HTTPS 登录 |
| [下载](https://www.idcsmart.com/wiki_list/932.html) | 清楚的版本和下载入口 | 选择一个正式 Core 版本，主机准备器校验并自动组装对应程序与资源 |
| [财务升级](https://www.idcsmart.com/wiki_list/641.html)、[V10 升级](https://www.idcsmart.com/wiki_list/934.html) | 备份、当前/目标版本、明确操作及完成核对 | 独立来源校验、备份元数据、兼容性检查和人工维护窗口；准备/暂存不显示为已安装 |
| [迁移恢复](https://www.idcsmart.com/wiki_list/793.html) | 应用版本与数据库恢复相互匹配 | 核对源码、Core、schema/checksum；不把换回程序目录当作数据库降级 |

上表的锁、哈希、权限隔离、幂等与失败状态是本项目的工程设计，不据官方产品页面推断对方具有相同实现或保证。

## 允许实施的最小范围

用户明确要求：可配置品牌，中文/English，默认 CNY、运营者独立配置币种和价格，保留历史 USD；原生单机 Linux amd64；独立运行时插件；裸程序与必要资源分开发行；安装、更新及相关中文文档随实现维护。

现有流程的必要补齐：

- 主机准备器自动校验和组装同一版本的完整目录，独占锁、不可覆盖及失败记录；不会切换 `current`、修改系统服务、创建凭据或执行数据库操作。
- 只读主机事实与数据库 schema 预检，区分空库、待迁移、当前和不兼容；读取结果不是服务、备份、恢复或全部权限已验证的证明。
- 备份输出机器可读 `BACKUP.json`，减少运维手写来源和迁移元数据；文件校验不等于数据内容或隔离恢复已验证。
- 仅在付款适配器禁用时，安全取消本人或管理员有权处理的未付订单，同时作废其唯一配对账单。未知服务关联、处理历史或状态不一致时拒绝。

客户创建已经有生产 CLI，套餐独立定价已经有管理界面，后台版本检查和运维交接已经存在；本轮复用这些能力。数据库账号/权限、秘密、迁移、首次管理员、systemd/Nginx 和实际切换仍由获授权主机管理员按步骤明确执行，不新增公开安装接口或 Web 提权。

## 保留给后续明确选择的内容

完整安装/升级执行器、套餐创建和规格维护、客户管理写接口、续费账单/期限政策、金额调整、账本/对账、退款/贷项与税票均不因竞品存在而自动加入本轮。营销、代理、积分、联盟、自动换汇、虚拟化控制和具体支付渠道不在范围内。不执行真实付款、退款、订阅变更或外部发信，也不测试用户服务器、取消的外部测试机或 Mac。

Contributors 展示仍未核实；既有 URL/权限拒绝保持有效，不重试绕过或主动发送 Support 请求。实际源码、测试、CI 和发行结论分别记录在 [VALIDATION.md](VALIDATION.md)，不能由本参考清单推导。
