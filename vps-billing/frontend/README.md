# Aster Cloud 前端

Vue 3 + TypeScript + Vite 的独立财务工作台。工作名「星屿云」可替换。原创界面采用清晰的层级、留白、系统字体、克制的蓝色与响应式布局，不使用外部字体、图片或第三方跟踪脚本。

## 本地运行

要求 Node.js 22.12+（本次在 Node.js 24 验证）。

```sh
npm ci
npm run dev
```

访问 http://localhost:5173。开发服务器默认只监听 localhost。API 默认代理到 http://127.0.0.1:8080，可用 API_PROXY_TARGET 覆盖。后端 APP_ORIGIN 必须与浏览器访问的 origin 一致；localhost 与 127.0.0.1 不是同一个 origin。

后端演示环境启用后，登录页显示客户和管理员体验按钮；生产环境不显示演示登录按钮。公开的示例密码只用于 APP_MODE=demo，不可用于生产。若 API 不可用，可由用户主动进入显著标注的只读设计预览。预览不发出任何交易写请求。

## 功能

- 客户：工作台、云服务器记录、套餐比较、订单确认与创建、账单详情、账单 CSV 导出、账户与安全信息。
- 管理员：运营概况、客户列表、全部订单、账单管理、审计记录、扩展中心。
- Cookie 会话、CSRF 请求头、订单幂等键；不在 localStorage 保存认证材料。
- 订单失败不会展示成功；支付未配置明确失败关闭；配置后的结账响应经 DTO、HTTPS、无凭据和有效期校验后，只展示手动打开的服务商链接（noopener noreferrer），不自动跳转、不收集银行卡信息、不标记已付款。
- 弹窗使用原生 dialog；键盘焦点、跳至主要内容、移动导航和 reduced-motion 样式。
- 订单、账单、客户和审计支持本地关键词筛选；金额使用服务器返回的整数最小货币单位。

账户资料修改、密码重置、MFA、税务发票、退款、真实支付和节点控制不在当前实现范围内。UI 明确说明这些限制，不提供假成功操作。

## 扩展中心（只读）

管理员可访问 /integrations，通过 GET /api/v1/admin/integrations 读取实际注册的支付与邮件适配器清单。卡片显示启用状态、能力、配置方式；详情抽屉展示配置字段名称、必填/密钥引用标记与限制，不显示字段值。就绪仅表示配置状态，不表示已经验证第三方服务连通性。加载失败会清除旧卡片并提供重试，不回显可能包含密钥的服务端诊断。

首版只支持服务端环境变量与密钥管理配置，重启生效；新增供应商须实现类型化接口、注册并重新构建。页面没有安装、开关、密钥输入或保存操作。客户看不到入口，直接访问也不请求管理员 API；真实权限仍由服务端强制验证。默认的 disabled 适配器不能收款或投递邮件。结账地址的服务商主机白名单由后端强制校验，前端另行校验 DTO、HTTPS 与有效期；点击前再次检查链接是否过期。短信、存储与节点控制明确标注规划中。只读预览使用显著标注的虚构清单，不发出 API 请求。

## 构建与检查

```sh
npm run typecheck
npm run test
npm run build
npm run format:check
npm audit --omit=dev
```

产物为 dist/。生产环境应由同源 HTTPS 反向代理提供静态资源和 /api/v1，而不是使用 Vite 开发服务器。History 路由需配置静态 fallback 到 index.html，API 错误不得 fallback 成 HTML。

测试包括金额/UTC/状态、CSRF/幂等头、错误响应失败关闭，以及 Vue 组件级只读预览、登录、创建订单和不可用支付流程。扩展测试覆盖管理员/客户隔离、真实清单读取、禁用状态、配置值不渲染、错误重试、过期请求隔离、抽屉关闭/重开及返回导航，以及有效结账外链和 javascript/http/URL 凭据/过期会话拒绝路径。组件测试使用显式模拟 API，不替代真实浏览器验收。

## 浏览器验收

启动 demo 后端与前端后执行：

```sh
npx playwright install chromium
npm run test:e2e
```

默认使用 Playwright 管理的 Chromium 并启用 Chromium 沙箱；可用 CHROMIUM_PATH 指向已经安装且受信任的浏览器。测试环境必须支持其正常安全机制，不应通过关闭沙箱来规避环境限制。

该脚本在演示环境内创建一个测试订单，验证登录、关闭/重开订单弹窗、下单、账单、支付不可用、筛选、移动导航、退出及管理员页面，并在 qa/ 生成本地截图。切勿指向生产系统。

本次云工作区运行限制阻止 Chromium 创建本地进程 socket，正式提权通路也因运行器文件系统错误失败。因而浏览器端 E2E、桌面/移动端截图和实际视觉验收未完成；未声称这些检查通过。构建、TypeScript、组件/单元测试、生产依赖审计和同源 API 代理读取已通过。上线前必须在受支持的浏览器环境运行测试并人工检查可读性、布局、键盘和真实支付集成。

## 代码结构

- src/App.vue：当前工作台页面、会话和交互编排。
- src/lib/api.ts：DTO、API 请求、金额/日期与状态呈现。
- src/components/IntegrationsPage.vue：管理员只读扩展注册表与配置说明抽屉。
- src/lib/integrations.ts：扩展 DTO、白名单字段校验与只读样例。
- src/lib/preview.ts：仅用于显式只读预览的虚构数据。
- src/style.css：响应式视觉系统，不依赖远程资源。
- tests/：单元、组件及浏览器场景。

这是可运行的第一阶段基础，不是生产合规或安全认证。后续宜按业务页面拆分组件、补充分页和可观测性、完成可访问性审计，并在真实部署拓扑下验证错误恢复和会话边界。
