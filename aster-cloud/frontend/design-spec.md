# Aster 云管理

## 方向与取舍

这是一套管理服务器、节点与操作任务的工作界面，不是销售首页。参考 Apple HIG 的内容优先、分层、明确反馈、可及性原则，不复制财务界面、已有截图或第三方产品。

放弃常见“统计卡仪表盘”：首屏直接是可搜索的实例清单。桌面以稳定窄侧栏和宽工作区呈现，移动端转为有焦点约束的导航抽屉；实例名称与当前状态优先，CPU/内存/磁盘作为同一行的规格。实例详情在完整页面呈现，危险操作只在确认对话框中完成。迁移使用四阶段向导，分别说明准备、安全传输、导入、激活，绝不因上一请求已受理而自动执行下一阶段。

## 视觉契约

- 瓷白画布 `#f5f6f8`，白色内容面 `#ffffff`，石墨文字 `#1d2533`，次级文字 `#536174`，分隔线 `#dce1e8`，蓝色操作 `#175cd3`。深色使用独立语义色，不反转整页。
- 系统字体栈，中文 PingFang SC / Microsoft YaHei；正文15px、辅助13px、页标题28px。正常字重400/500/600，不用细灰字制造高级感。
- 4/8/12/16/24/32间距；内容最大1440px。44px最小交互高度。控件10px、内容组16px、浮层20px，不让所有内容都变成等尺寸卡片。
- 边界用于表达分组；阴影只用于浮层。不做炫光、营销渐变、装饰数字或无意义统计。
- 动效只回应交互：120–180ms透明度与小幅位移；尊重reduced-motion。骨架只在加载阶段，失败绝不显示空列表。

## 组件与状态所有权

- `api/client.ts`：同源真实HTTP、cookie、CSRF、严格JSON、安全错误分类，无演示回退、无自动重试。
- `useSession`：身份与epoch、权限、登出后清空资源；迟到响应不得恢复旧会话。
- `useMutation`：稳定32位小写hex意图key；发送后结果未知锁定，保留key，不能通过关闭重开自动重发。只把202叫“已受理”，不叫“已完成”。
- `UiOverlay`：独立浮层生命周期、焦点锁定/恢复、Escape/背景/浏览器返回；忙碌时不关闭。
- `UiSelect`：自定义listbox，方向键/Home/End/Enter/Escape和类型搜索，无原生select。
- `UiButton / StateBlock / StatusBadge / ToastStack`：统一忙碌、空、错、状态反馈，不依赖颜色传达意义。
- 页面只消费明确DTO，测试fixtures仅在tests下，生产入口绝不导入。

## 安全与验收边界

真实接口默认 `/console/v1`；不提供用户可切换的数据来源。权限以服务端返回为准，未知权限禁止危险动作。危险操作必须逐字输入实例ID，最终由后端确认。网络未知时保留意图并引导查看任务，不能假成功/自动再次派发。CSRF和会话只留内存，密码不持久化。

本地执行typecheck、Vitest、format、build；实际320/375/768/1440浏览器与真实后端由root另行验收，不能以单元测试替代视觉验收。

## VPC、路由与 NAT 管理

- 入口 `/networks/overlays`，与节点网络、IP 地址池、地址分配放在同一层导航；集群选择保存在 URL，浏览器返回恢复上下文。主要工作区是 VPC、当前配置和变更记录，不加装饰统计卡。
- VPC 可以采用预批准映射 ID，也可以新建 ID；后者明确标为“尚未映射节点”，不会绕过节点映射批准。VPC 元数据保存不冒充网络已接通。
- `OverlaySelectionEditor` 管理完整成员与网关选择；`OverlayNATEditor` 管理批准出口、SNAT 和端口映射。只展示安全候选投影，不提供任意宿主命令、设备路径或裸 JSON 编辑器。NAT 引用仍存在时不能悄悄移除网关或目标成员。
- `OverlayEpochDialog` 管理计划/恢复确认；恢复固定原 SHA-256、新操作 ID，可保留原配置或明确提交完整替换。根配置变化时禁普通变更，未批准迁移时禁恢复。故障成员保留身份；仅明确删除的实例可由操作员移出成员表。
- `OverlayEpochPage` 展示全部节点的准备、应用、放行三阶段、完整回执代码和原版本依据；继续执行、只读核对、恢复都是独立显式动作。节点确认不等于已完成真实流量验收。
- `useOverlayMutation` 在发送前持久化非秘密的完整意图，并按账号/集群/原版本锁定。未知响应时关闭、重开、更改草稿、刷新不产生另一个 POST；只读核对须匹配完整原意图，迟到的旧页面/旧会话响应不解锁。存储不可用或损坏时不发送。
- 新增组件仍使用现有语义色和自定义 UiSelect/UiOverlay。手机端成员、端口规则、节点阶段改为单列；桌面保留宽表格式分组。表单忙碌状态、焦点、Escape、背景关闭、浏览器返回复用已验证的浮层契约。
- 通知只补充页面与任务中的持久状态，不承担最终成功判定。信息提示最多一条、五秒自动关闭，鼠标停留或键盘阅读时暂停；错误去重且有界，不按计时消失。弹窗打开时后台通知隐藏并排除交互，层级低于遮罩；语言或身份变化清除旧文字，离场清理计时器，不能堆叠遮挡手机确认按钮。

## 公网 IPv4 出口

- 保留原 NAT 编辑器的状态边界与视觉语言：石墨正文、瓷白/深色语义面、蓝色选中、细边界；不另加全局开关或装饰统计。SNAT 与出口范围在桌面成对展示，窄屏改为单列；出口 IPv4 和节点身份始终就近显示。
- 出口范围使用现有 `UiSelect`，明确区分“仅指定网段”和“公网 IPv4”。只有节点允许公网且出口为有效公网单播地址时才能选择公网；未开放时显示原因，不把隐藏或不可点当作完整反馈。关闭 SNAT 同时移除公网选择，独立 DNAT 规则保持不变。
- 指定网段可明确留空，表示没有指定路由，不隐式扩展为默认路由。公网模式独立控制公网访问；私有、保留与管理地址仍受保护，原 DNAT 来源/端口合同不扩大。
- 配置与恢复对话框对公网范围增加显式确认，复用原集群名/变更 ID 确认与忙碌、焦点、关闭保护。复选框保留原生键盘行为，外观由当前设计 token 绘制。选择不冒充生效，受理后仍需查看各节点回执。
- 概览、历史版本详情与原配置恢复均展示出口范围。出口地址只有在完整节点/VPC/网关/配置 ID/SHA-256 对应时才引用当前安全投影；无法核实时不猜测旧版本地址。
- `internet_egress_enabled` 仅在 true 时进入规范化意图，旧省略/false 等价；公网与非公网意图绝不等价。未知 POST 的只读核对仍匹配完整模式，不以丢失新字段的 GET 解除锁定。

## 公网 IP 库存与分配

- `/networks/public-ips` 是网络第二级导航，集群、池/分配记录及游标保存在URL；不新增装饰统计卡。数量只表示库存，不从租约差集推断空闲。
- `PublicIPsPage` 拥有列表与确认后刷新；`PublicIPDialog` 拥有范围/列表输入、精确VPC/出口选择及typed IP回收确认；`usePublicIPMutation` 独立持久保管完整actor/action/target/request；严格DTO和原操作GET核对在 `api/public-ip.ts`。
- 创建、补充、启停、分配、回收以服务端固定结果为准。丢ACK跨关闭/刷新仍阻断新地址POST，GET须匹配原账号/ID/动作/目标/完整请求及相符结果。保留released历史，显示服务端绑定/待确认/不可回收状态，不把预留叫网络已接通。
- NAT选址仅列精确VPC/owner/node/profile的reserved租约；`public_ipv4`进入新冻结意图及完整比较，缺省不改旧字节。历史显式IP从冻结版本读取，不从当前默认地址猜旧绑定。
- 复用UiSelect/UiOverlay/UiButton、可见错误、44px交互及焦点/dirty关闭契约；新表单novalidate配合自定义错误，不弹系统校验气泡。桌面紧凑分组，≤600px单列，中英浅深主题及实际320/390/1440浏览器另验。
